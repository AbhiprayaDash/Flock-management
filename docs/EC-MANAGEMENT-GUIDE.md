## Day-range phase schedules — 11 November 2026

The default organization plan now covers early brooding (1–7), late brooding/transition (8–14), growing (15–28), and finishing/pickup (29 onward). These are editable operational groupings, not universal biological or feed-change thresholds. Each phase includes management guidance and its own timed SOP instructions. The Management Guide highlights the actual batch phase and allows browsing all phases. Its owner editor supports phase names, day ranges, guidance, check titles/instructions and per-phase times. Validation requires continuous non-overlapping coverage from day 1 through an open-ended final phase.

The dashboard derives tasks from the checklist date, so historical dates use the corresponding flock age. Existing task keys, per-batch/date completion identity, server timestamps and completed-batch protections are retained. New task records snapshot the scheduled time, instruction and phase; saved titles/instructions are preserved when displaying records. Older customized guides without phases inherit the new defaults with their existing scheduled times; their reference content remains intact. No database migration is needed.
