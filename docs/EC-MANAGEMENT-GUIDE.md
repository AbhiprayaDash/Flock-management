The Management Guide opens with 13 recommended sections without setup, including house preparation, chick arrival, brooding, crop fill, minimum/transition/tunnel ventilation, cooling pads and humid weather, feed/water, litter, power/alarms, lighting/growth and company pickup. References are linked per section, reviewed on 10 November 2026. They include Aviagen 2025 handbooks, Cobb, University of Georgia ventilation guidance, Mississippi State extension, TNAU and Government of India guidance. Text is a practical synthesis, not a complete reproduction or a substitute for strain-specific instructions. Numerical recommendations retain their measurement location and operating conditions.

Organization owners are the admin role. Open Management Guide → Edit guide & SOP schedule. Edit titles, stages, guidance, reference links and local daily review times. Save shares the organization's customized profile across its farms and batches. Loading defaults changes the editor only until saved; Cancel discards the draft. Existing profile fields are preserved. Default content remains available before any batch exists. No controller setting, rating threshold or vaccination program is changed by editing this guide.

The existing profile record and organization RLS are used. Only owners can write profiles; the guide API additionally verifies owner membership. Version checks refuse conflicting updates. URLs must use HTTPS, schedules use valid 24-hour times, and profile content is bounded and rendered as plain text. Database audits retain saved revisions.

The Daily SOP uses suggested local review times; continuous monitoring and repeated checks remain necessary. Task completion timestamps come from the existing database trigger, and reopening shows the database update time. Historic checklist dates do not backdate action timestamps. Saved task schedules are retained, while unrecorded tasks use the current organization schedule. Old records without a completion timestamp say so. Existing batch/date/task uniqueness and completed-batch read-only rules remain enforced. No automatic completion or notifications are implied.

The default organization plan now covers early brooding (1–7), late brooding/transition (8–14), growing (15–28), and finishing/pickup (29 onward). The Management Guide highlights the actual batch phase and allows browsing all phases. Its owner editor supports phase names, day ranges, guidance, check titles/instructions and per-phase times. ## Seasons and measured shed conditions — 11 November 2026

The phase schedule now has summer/hot, rainy/humid and winter/cold guidance overlays for climate, water, litter and health checks. General guidance remains usable with no season chosen. In Management Guide, a seasonal preview shows the combined phase/SOP plan; this preview does not alter recorded conditions. Owners can edit seasonal guidance and example screening thresholds in the existing shared guide editor. Older guides receive seasonal defaults without losing phase content or customized times.

On the dashboard, authorized SOP staff can record the selected checklist day's season, observation time, optional measured shed temperature/humidity and panting/huddling/wet-litter observations. These are ordinary batch-scoped checkpoint records, protected by the existing organization/assignment RLS, revision checks and audits. The API validates data ranges and date limits, obtains the timezone from the authorized batch, and refuses completed batches. Display distinguishes local observation time from database save time. No outside weather API or live sensor is connected. Readings and season are not silently carried across dates or batches. Duplicate legacy observations use the latest update.

Recorded readings trigger example high-temperature (35°C) and high-humidity (80%) reminders; owners may adjust them. These are screening reminders, not universal comfort limits, equipment commands, or health grades. Bird signs add checks regardless of season. No low-temperature threshold is inferred from the calendar; huddling prompts chick-level warmth and draft checks. Season alone does not generate measured-condition warnings. Changing guidance shows a recheck message beside previously recorded instructions rather than erasing completions or backdating timestamps.

References supporting the seasonal synthesis: Mississippi State's [evaporative cooling](https://extension.msstate.edu/publications/evaporative-cooling-systems-how-and-why-they-work), [winter ventilation](https://extension.msstate.edu/publications/broiler-house-ventilation-during-cold-weather), and [minimum ventilation](https://extension.msstate.edu/publications/minimum-ventilation-can-challenge-broilers), alongside the existing water, biosecurity and breeder references. The recommended screening values are app defaults, not values attributed as a universal recommendation to these sources.

## Overview daily air-quality monitoring

Overview now shows measured oxygen (%), ammonia (ppm) and relative humidity (%) with recommended references. Defaults are oxygen >19.6%, ammonia <10 ppm, humidity 60–70% on days 1–3 and 50–70% thereafter. These are management references, not a guarantee of health or personnel safety. Sources: [Cobb air-quality guidelines](https://emeabook.cobbvantress.com/view/984942518), [Aviagen placement conditions](https://aviagen.com/assets/Tech_Center/BB_Resources_Tools/Poster-Eval-Brooding-Temperature-EN-r1.pdf) and [UGA environmental factors](https://fieldreport.caes.uga.edu/publications/B1287/environmental-factors-to-control-when-brooding-chicks/). Owners can adjust the references in the guide editor. The humidity operating range is separate from the higher humidity alert threshold used for cooling checks.

Record measurements in the Daily SOP conditions form using appropriate calibrated instruments at representative bird-level locations. Oxygen and ammonia remain optional; older observations normalize them to unknown, never zero. The current-day cards and expandable history expose missing days, observation times, zero ammonia and all batch dates. The history initially shows seven days and supports the entire batch; it displays the latest corrected observation per date, not averages or continuous sensor coverage, and compares against current reference settings. Low oxygen and high ammonia readings add ventilation/safety checks; smell is not a substitute for measuring ammonia. No sensor integration or oxygen/ammonia inference from mortality, season or other readings is provided.

## Bird behavior & early signs

A dedicated sidebar section explains eight patterns: comfortable distribution, huddling/piling, panting/heat avoidance, drinker/feeder access changes, inactivity/isolation, gait problems, respiratory signs and neurological/collapse signs. Each includes meaning/uncertainty, immediate checks/actions, review urgency, source link, and separate summer/rainy/winter considerations. A season selector highlights one set while an expandable comparison retains all seasons. The page is educational, not a video-analysis system, disease predictor or diagnostic score. It explains that some disease causes sudden losses without behavioral warning.

The recording checklist asks for flock age, date/time, lighting period, location, affected count, onset, intake and actual shed conditions. It links to existing health records, where staff can document the concern. The sidebar page's Add case action opens the existing concern form. No health case, treatment or diagnosis is automatically created by reading a pattern. Severe breathing, collapse, neurological signs and rapidly increasing mortality require prompt veterinary involvement independently of season.

Sources include Aviagen chick behavior guidance, Mississippi State heat/water/winter references, USDA APHIS signs of illness, Extension Poultry general signs, and Merck neurological/respiratory disease guidance. Reference links appear per pattern. The organization owner can customize the library in the existing Management Guide editor, with validated text lengths, unique IDs and HTTPS source links. Existing guides receive the library by default without losing custom seasonal or phase content.
